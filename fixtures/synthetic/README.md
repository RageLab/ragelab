# Synthetic fixtures

The files in this directory are deterministic regression fixtures generated by RageLab scripts. They contain no Rockstar or third-party asset data.

Synthetic fixtures test known parser and writer invariants. They do not replace validation against privately owned real-world assets.

## `simple.ymap`

Generated by `scripts/generate_synthetic_ymap.py`.

It exercises the `ragelab-ymap` reader with:

- META root `CMapData`;
- one pointer-array entity;
- one `CEntityDef`;
- one physics-dictionary hash;
- deterministic map name and parent hashes.

Expected semantic values are in `simple.expected.txt`.

## `simple.ytyp`

Generated by `scripts/generate_synthetic_ytyp.py`.

The YTYP contains one base archetype whose name hash matches the entity in `simple.ymap`. Its model and dictionary hashes are deterministic `joaat` values listed in `simple-ytyp.expected.txt`.

## `ydr/simple.ydr`

Generated by `scripts/generate_synthetic_ydr.py`.

The fixture is a minimal legacy resource-v165 YDR with:

- one active high LOD;
- one model and one geometry;
- three vertices and one triangle;
- Position Float3, Normal Float3, Colour0, and TexCoord0 Float2;
- deterministic model and geometry bounds;
- drawable name `test_drawable`.

It is used to test YDR parsing, rigid-translation eligibility, declarative planning, non-destructive apply, semantic reopen, and source preservation. The same generator also writes `ydr/editable.ydr`, which adds two existing shaders and two compatible texture bindings for controlled rebind coverage.

The generator also writes `ydr/embedded.ydr`, whose proven `DiffuseSampler` resolves to an embedded 4x4 BC1 texture, and `ydr/external-diffuse.ydr`, whose proven `DiffuseSampler` names `test_diffuse` but contains no embedded dictionary. The latter pairs with `ytd/test_diffuse.ytd` to test explicit caller-supplied dependency resolution.

Regenerate with:

```bash
python scripts/generate_synthetic_ydr.py
```

## `ydd/editable.ydd`

Generated by `scripts/generate_synthetic_ydd.py`.

The fixture is a Legacy resource-v165 drawable dictionary containing one complete editable drawable with:

- deterministic dictionary hash and drawable name metadata;
- one model, one geometry, three vertices, and one triangle;
- two existing shaders;
- two compatible existing texture bindings;
- layout provenance sufficient for conservative rigid translation and rebind writers.

It is used for YDD parsing, per-drawable capability discovery, declarative planning, non-destructive apply, dictionary identity preservation, and semantic reopen tests.

Regenerate with:

```bash
python scripts/generate_synthetic_ydd.py
```

## `yft/no-main-drawable.yft`

Generated by `scripts/generate_synthetic_yft.py`. This Legacy v162 RSC7 contains a valid padded FragType root with a null pristine main-drawable pointer. It is intentionally render-ineligible and exists to prove that YFT browser/native preview fails closed instead of guessing a damaged/physics drawable.

## `ytd/test_diffuse.ytd`

Generated by `scripts/generate_synthetic_ytd.py --name test_diffuse --output fixtures/synthetic/ytd/test_diffuse.ytd`.

This copyright-free 4x4 RGBA8 dictionary uses the same deterministic payload as `ytd/simple.ytd`, but its texture is named `test_diffuse`. It matches the proven diffuse binding in `ydr/editable.ydr` and `ydd/editable.ydd`, so browser tests can exercise caller-supplied external YTD resolution without GTA/RPF data.

## `ybn/preview.ybn`

Generated by `scripts/generate_synthetic_ybn.py`.

This fixture preserves the same deterministic Legacy resource-v43 collision layout as `ybn/simple.ybn`, but contains both:

- one triangle mesh primitive using vertices 0, 1, and 2;
- one sphere shape primitive using material slot 1.

It is used to test bounded collision preview, material/child metadata, shape serialization, local-only spatial semantics, and safe geometry omission when preview budgets are exceeded.

## `ymap-relations/`

Generated by `scripts/generate_synthetic_ymap_relations.py`.

These YMAPs reuse the simple META layout and change only `CMapData.name` and `parent` to form a deterministic graph: one parent, two direct children, and one grandchild. They exercise structural reverse-parent closure without relying on filename conventions.

## `stream/`

The `stream/` directory combines generated YMAP and YTYP files with empty placeholder `.ydr`, `.ydd`, `.ytd`, `.ybn`, and `.ycd` files whose names intentionally match synthetic hash references.

It also contains `gtxd.meta` and two empty parent YTD placeholders for a two-hop texture-parent chain. These placeholders are dependency-index fixtures only; they are not valid model, texture, collision, or clip resources.

## Validation

Run the independent fixture checks with:

```bash
python scripts/validate_synthetic.py
python scripts/validate_synthetic_ymf.py
```
