# Synthetic fixtures

The files in this directory are deterministic regression fixtures generated by RageLab scripts. They contain no Rockstar or third-party asset data.

Synthetic fixtures test known parser and writer invariants. They do not replace validation against privately owned real-world assets.

## `simple.ymap`

Generated by `scripts/generate_synthetic_ymap.py`.

It exercises the `ragelab-ymap` reader with:

- META root `CMapData`;
- one pointer-array entity;
- one `CEntityDef`;
- one physics-dictionary hash;
- deterministic map name and parent hashes.

Expected semantic values are in `simple.expected.txt`.

## `simple.ytyp`

Generated by `scripts/generate_synthetic_ytyp.py`.

The YTYP contains one base archetype whose name hash matches the entity in `simple.ymap`. Its model and dictionary hashes are deterministic `joaat` values listed in `simple-ytyp.expected.txt`.

## `ydr/simple.ydr`

Generated by `scripts/generate_synthetic_ydr.py`.

The fixture is a minimal legacy resource-v165 YDR with:

- one active high LOD;
- one model and one geometry;
- three vertices and one triangle;
- Position Float3, Normal Float3, Colour0, and TexCoord0 Float2;
- deterministic model and geometry bounds;
- drawable name `test_drawable`.

It is used to test YDR parsing, rigid-translation eligibility, declarative planning, non-destructive apply, semantic reopen, and source preservation.

Regenerate with:

```bash
python scripts/generate_synthetic_ydr.py
```

## `ymap-relations/`

Generated by `scripts/generate_synthetic_ymap_relations.py`.

These YMAPs reuse the simple META layout and change only `CMapData.name` and `parent` to form a deterministic graph: one parent, two direct children, and one grandchild. They exercise structural reverse-parent closure without relying on filename conventions.

## `stream/`

The `stream/` directory combines generated YMAP and YTYP files with empty placeholder `.ydr`, `.ydd`, `.ytd`, `.ybn`, and `.ycd` files whose names intentionally match synthetic hash references.

It also contains `gtxd.meta` and two empty parent YTD placeholders for a two-hop texture-parent chain. These placeholders are dependency-index fixtures only; they are not valid model, texture, collision, or clip resources.

## Validation

Run the independent fixture checks with:

```bash
python scripts/validate_synthetic.py
python scripts/validate_synthetic_ymf.py
```
