# Fixtures

Fixtures are required for format confidence, but proprietary assets must not be committed casually.

## Private local fixtures

Put personally owned/test map files under:

```text
fixtures/private/
```

This directory is ignored by Git.

Recommended initial set:

- `simple.ymap` — small map with a few normal `CEntityDef` entities;
- its `.ytyp` for milestone 2;
- `lod_parent.ymap` and `lod_child.ymap`;
- one YMAP containing an MLO instance;
- `_manifest.ymf` generated by CodeWalker for later writer comparison.

## Committable fixtures

Prefer tiny resources synthesized by tests or assets with explicit redistribution permission. Synthetic tests should target one invariant at a time: RSC7 decompression, META pointer resolution, structure descriptors, pointer arrays, etc.

Do not commit GTA V base-game assets or paid/third-party FiveM map assets without permission.

## Synthetic YTYP

`synthetic/simple.ytyp` is generated by `scripts/generate_synthetic_ytyp.py`.
It contains one `CMapTypes` root and one `CBaseArchetypeDef` with fixed hashes
matching `simple-ytyp.expected.txt`. It contains no Rockstar asset bytes.

## Synthetic GTXD chain

`synthetic/stream/gtxd.meta` declares a two-hop parent texture-dictionary chain for `test_textures.ytd`. The parent/grandparent YTD files are empty placeholders; the fixture exercises dependency closure and filtered FiveM metadata export without proprietary texture bytes.
