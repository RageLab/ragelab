# Fixtures

Fixtures are required for format confidence, but proprietary assets must not be committed casually.

## Private local fixtures

Put personally owned test assets under:

```text
fixtures/private/
```

This directory is ignored by Git.

Private fixtures are useful for validation against real game data, but they must not become build or test dependencies for the public repository.

## Committable fixtures

Prefer tiny resources synthesized by scripts or assets with explicit redistribution permission. Synthetic tests should target one invariant at a time: RSC7 decompression, META pointer resolution, structure descriptors, vertex layouts, writer behavior, and dependency closure.

Do not commit GTA V base-game assets or paid or third-party FiveM assets without permission.

## Synthetic YMAP and YTYP

`synthetic/simple.ymap` and `synthetic/simple.ytyp` are generated by the scripts under `scripts/`. They contain deterministic test structures and hashes and no Rockstar asset bytes.

## Synthetic YDR

`synthetic/ydr/simple.ydr` is generated by `scripts/generate_synthetic_ydr.py`.

It contains a minimal legacy resource-v165 drawable with one model, one triangle, a known vertex declaration, deterministic bounds, and no proprietary data. It is used for parser regression and for non-destructive declarative `ydr.translate` plan/apply tests.

Regenerate and validate:

```bash
python scripts/generate_synthetic_ydr.py
python scripts/validate_synthetic.py
```

## Synthetic GTXD chain

`synthetic/stream/gtxd.meta` declares a two-hop parent texture-dictionary chain for `test_textures.ytd`. The parent and grandparent YTD files are empty placeholders; the fixture exercises dependency closure and filtered FiveM metadata export without proprietary texture bytes.
